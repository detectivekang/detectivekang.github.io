개발자 소개 & 블로그 안내

안녕하세요! DetectiveKang 포트폴리오 및 프로젝트 모음 페이지에 오신 것을 환영합니다. 저는 주로 웹 생태계에서 작동하는 다양한 유틸리티 서비스, 효율적인 관리 시스템, 그리고 브라우저 기반의 캐주얼 웹 게임을 개발하고 있습니다.

단순히 코드를 작성하는 것에 그치지 않고, 사용자 경험(UX)을 개선하고 실제로 유용하게 활용될 수 있는 애플리케이션을 구현하는 것을 목표로 합니다. 본 사이트는 그동안 개발해 온 다양한 오픈소스 프로젝트와 웹 애플리케이션들의 기술 스택, 주요 기능, 그리고 데모 링크를 한눈에 확인할 수 있도록 정리한 공간입니다.

주요 프로젝트 목록

실시간 밸런스 게임 앱 (Live Demo)

사용자들이 다양한 주제의 질문에 직접 투표하고 결과를 실시간 통계로 확인할 수 있는 유저 참여형 인터랙티브 웹 앱입니다.

JavaScript Interactive Poll App

악기 수리 및 케어 서비스 (musicfix)

악기 사용자들을 위한 맞춤형 수리 및 정비 케어 플랫폼입니다. 클라이언트 기반의 빠른 반응형 UI를 제공하여 간편하게 악기 상태를 체크하고 필요한 서비스를 안내받을 수 있도록 구성되었습니다.

TypeScript Next.js Web Service

인생역전 랜드스케이프 (Life Reverse)

웹 브라우저에서 바로 즐길 수 있는 방치형/클리커 아케이드 게임입니다. 직관적인 UI와 효율적인 상태 관리를 바탕으로 자산을 늘려가는 재미를 제공하며, 모바일 및 데스크톱 환경 모두에 최적화되어 있습니다.

HTML5 Canvas JavaScript Web Game

교회 출석 및 통합 관리 시스템

소규모 공동체 및 교회 데이터를 효율적으로 관리할 수 있는 출석 체크 솔루션입니다. 출석 통계 시각화, 명단 관리, 간편 데이터 조회 기능을 지원하여 관리자의 업무 효율을 돕습니다.

JavaScript Web App Management

클래식 테트리스 게임

순수 자바스크립트 로직을 활용해 만든 브라우저용 테트리스 퍼즐 게임입니다. 블록 회전, 컬리전 체크, 점수 계산 시스템 등 핵심 게임 엔진 구조를 체계적으로 구현했습니다.
